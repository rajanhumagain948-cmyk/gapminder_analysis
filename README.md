# 🌍 Gapminder Analysis

Gapminderの長期データを使用して、**世界の人口・健康・経済・出生率の変化**を分析したデータサイエンスプロジェクトです。

## 📊 Analysis

以下の指標を中心に、1800年代から現在までの長期的な変化を分析しました。

* 👥 Population
* ❤️ Life Expectancy
* 💰 GDP per Capita
* 👶 Fertility Rate
* 🏥 Child Mortality

国や地域を比較しながら、世界の発展と人々の生活水準がどのように変化してきたのかを考察しました。
